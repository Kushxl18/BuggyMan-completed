## 1. Directory Structure & Evidence Classification

All raw test execution outputs, terminal logs, build artifacts, and security scan outputs are systematically categorized under the following subdirectories:

```
testing/evidence/
├── unit/            # Backend unit tests and model method execution logs
├── integration/     # Service integration and cross-module test logs
├── api/             # Django REST Framework API contract and response logs
├── e2e/             # End-to-end user journey and workflow logs
├── security/        # Rate limiting, input validation, and sandbox escape test logs
├── performance/     # Subprocess timeout, latency, and throughput logs
├── builds/          # Production bundle compilation and lint logs
└── deployment/      # System checks, migration verification, and health logs
```

## 3. Data Sanitization & Compliance

In strict compliance with security and privacy requirements:
- All real passwords, bearer tokens, and session secrets have been sanitized and redacted.
- No production database credentials or private keys are committed in raw logs.
- Evidence contains genuine terminal outputs generated by actual test runners.
