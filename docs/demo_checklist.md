# BuggyMan Demo & Comprehensive Testing Checklist

This checklist provides a step-by-step validation guide for live demonstrations, major project evaluation, and quality assurance testing of BuggyMan.

---

## 1. User Authentication & Onboarding
- [x] **New User Registration**: Register a new student account (`POST /api/register`). Verify valid JWT token return and initial profile setup.
- [x] **Onboarding Tour**: Log in as a new user. Verify 5-step interactive onboarding modal pops up automatically (`OnboardingModal.jsx`). Complete tour and confirm `localStorage` completion flag is saved.
- [x] **Existing User Login**: Log in with existing credentials (`POST /api/login`). Confirm seamless navigation to Dashboard without intrusive onboarding popup.
- [x] **Manual Tour Re-trigger**: Click "Platform Tour" button on Dashboard hero banner. Verify tour modal re-opens smoothly.

---

## 2. Debugging Arenas & Challenge Flows
- [x] **Code Lab Arena**: Select a React/JavaScript challenge (e.g. "Fix React State Updates"). Verify problem statement, files explorer, and test case list.
- [x] **SQL Lab Arena**: Select an SQL challenge (e.g. "Incorrect WHERE Clause Returns Extra Records"). Verify query execution in SQLite in-memory sandbox.
- [x] **Frontend Studio Arena**: Select a CSS/Layout challenge. Verify styling assertions and rendering.
- [x] **Run Code (Ephemeral Execution)**: Click `Run Code`. Observe `Running...` spinner. Verify stdout/stderr and test case pass/fail feedback without earning XP.
- [x] **Incorrect Solution Attempt**: Submit code with intentional bugs. Verify failed test case highlights, error messages, and 0 XP awarded.
- [x] **Correct Solution Attempt**: Submit valid bug repair. Observe `Evaluating...` spinner. Verify transition to `ResultPage.jsx`, +100 XP awarded, streak updated, and celebratory toast displayed.

---

## 3. AI Intelligence Suite
- [x] **Graduated Hints**: Click `Ask AI Hint`. Unlock Level 1 (Conceptual), Level 2 (Directional), and Level 3 (Solution Clues). Verify no full code spoilers.
- [x] **AI Diagnostic Feedback**: Execute failing code. Click `AI Feedback`. Verify root-cause defect analysis generated from test failure logs.
- [x] **AI Solution Explainer**: On `ResultPage.jsx`, click `Explain Solution`. Verify step-by-step explanation of why the bug occurred.
- [x] **AI Challenge Generator**: In Admin Console or Challenge Catalog, generate a new challenge using AI (`POST /api/challenges/generate`). Confirm automated starter/solution validation.

---

## 4. Adaptive Learning & Analytics
- [x] **ML Recommendations**: Inspect Dashboard and Catalog. Verify personalized challenge recommendations generated by ML recommender (`/api/challenges/recommendations`).
- [x] **Skill Profiler & Weakness Detector**: Navigate to `Analytics.jsx`. Verify error classification (`state_mutation_error`, `database_error`) and weakness alerts.
- [x] **Personalized Learning Path**: Fetch learning path (`/api/challenges/learning-path`). Verify 5-stage progressive curriculum.

---

## 5. Leaderboard, Streaks & Gamification
- [x] **Real-Time XP Sync**: Submit successful challenge solution. Verify total score increases instantly on Navbar and Dashboard.
- [x] **Streak Tracking**: Complete daily challenge. Verify streak counter increments and badge unlocks.
- [x] **Leaderboard Rankings**: Navigate to `Leaderboard.jsx`. Confirm rankings derive 100% from backend ORM query with multi-column ordering (`-total_score`, `-challenges_solved`, `-streak`, `id`) and dense rank tie-breaking.
- [x] **College Filter**: Search or filter leaderboard by college. Verify query filtering works.

---

## 6. Admin Console & Maintenance
- [x] **Admin Privilege Security**: Log in as student. Attempt `GET /api/admin/users`. Confirm `403 Forbidden` response. Log in as admin. Confirm access granted.
- [x] **Challenge Lifecycle Management**: Create a challenge draft. Transition status `Draft` $\rightarrow$ `Review` $\rightarrow$ `Published`. Verify completeness validation blocks invalid publish attempts.
- [x] **Issue Report Resolution**: Submit issue report from workspace (`ProblemStatementPanel.jsx`). In Admin Console (`AdminDashboard.jsx`), view report, add resolution notes, and update status to `Resolved`.
- [x] **System Health Check**: Access `GET /api/health`. Confirm `200 OK` reporting database, cache, and evaluator status.
- [x] **Full Backup Export & Verification**: In Admin Console, trigger full backup export (`GET /api/admin/backup/export`). Submit backup payload to `POST /api/admin/backup/verify` and confirm `valid: true`.

---

## 7. Security & Edge Case Validation
- [x] **JWT Security**: Send request with invalid Bearer token. Verify `401 Unauthorized` response.
- [x] **Path Traversal Protection**: Submit file name containing `../../etc/passwd`. Verify file path is sanitized to basename safely inside temp directory.
- [x] **Command & Extension Injection**: Attempt SQL extension loading (`load_extension`). Verify execution blocked by SQLite sandbox bounds.
- [x] **Rate Limiting**: Trigger 35 rapid code executions. Verify `429 Too Many Requests` returned with `retryAfterSeconds`.
- [x] **Log Redaction**: Verify passwords, secrets, and JWT tokens are redacted as `[REDACTED]` in log outputs.
